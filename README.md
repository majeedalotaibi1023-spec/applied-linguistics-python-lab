# Applied Linguistics Python Lab

This repository documents my personal experiments with Python as I develop my technical skills alongside my academic work in applied linguistics.

The first project explores basic word-frequency patterns in a small synthetic collection of English-language learner reflections. The purpose is to practice working with text data in Python while thinking about how simple computational methods can be used to explore language-related data.

## Current project

The current script:

- reads text from a file
- converts the text to lowercase
- removes punctuation
- tokenizes the text into words
- removes a small set of common stop words
- counts word frequencies
- displays the most frequent remaining words

The dataset is synthetic and was created specifically for this repository. It does not contain student records, research-participant data, or confidential information.

## What I am practicing

This project gives me practice with Python concepts such as file handling, functions, lists, dictionaries, loops, text preprocessing, and sorting results.

This is an early learning project rather than a complete natural language processing system. I plan to expand the repository as I develop stronger Python and data-analysis skills.
